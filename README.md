## 계정
3부서와 같은 통합 계정(noticecheck 기준)을 씁니다. 이미 승인된 사람은 바로 로그인됩니다.
인트라넷 관리자로 로그인하면 퇴근보고에서도 팀장 권한이 자동으로 부여되어 팀 전체 데이터가 보입니다.
다른 사람에게 팀장 권한을 주려면 퇴근보고 화면의 설정 · 데이터 → 멘토 편집에서 그 사람의 팀장을 체크하세요.
