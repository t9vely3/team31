# AIX 3-1팀 인트라넷 (보고 · 매출)

```
index.html          인트라넷 껍데기 (왼쪽 메뉴, 통합 로그인, 화면 테마, 인쇄)
apps/report.html    퇴근보고 (오전·퇴근 보고, 월간 입력표, 팀 마감률)
apps/sales.html     상담 매출 관리 (상담·결제 기록, 미수 잔액, 월별 추이)
```

3부서 인트라넷과 **별도 사이트**입니다. 이 주소에는 3-1팀 화면 두 개만 들어 있고,
수강생 관리파일·견적서 같은 3부서 업무는 보이지 않습니다.

## 어디에 올리나

같은 저장소 안의 하위 폴더에 올리면 됩니다. 예를 들어 `team31/` 폴더에 `index.html`과 `apps/`를 넣으면
주소는 `https://t9vely3.github.io/team31/` 이 됩니다. 3부서 인트라넷과 도메인이 같아서
파이어베이스 승인된 도메인은 추가로 등록할 필요가 없습니다.

저장소를 아예 따로 만들어도 됩니다. 그 경우 각 파이어베이스 프로젝트의 승인된 도메인에 새 주소를 넣어야 합니다.

## 계정

3부서 인트라넷과 **같은 통합 계정**을 씁니다. 가입 신청과 승인도 같은 곳(noticecheck 프로젝트)을 보므로,
이미 승인된 사람은 이 주소에서 바로 로그인됩니다. 승인은 3부서 인트라넷이나 이 사이트의
왼쪽 아래 **팀원 관리**에서 똑같이 할 수 있습니다.

3-1팀만 따로 관리하고 싶으면 기준 프로젝트를 다른 것으로 바꿔야 합니다. 그때는 `index.html`의
`sso-config`에서 `master: true` 프로젝트를 교체하면 됩니다.

## 연결된 파이어베이스 프로젝트

| 용도 | 프로젝트 |
| --- | --- |
| 기준 계정(가입·승인) | noticecheck-80980 |
| 퇴근보고 | home-a4d02 |
| 상담 매출 관리 | complete-55019 |

`home-a4d02` 와 `complete-55019` 두 곳에서 Authentication의 **이메일/비밀번호** 사용 설정과
**승인된 도메인** 등록을 확인하세요. 안 되어 있으면 로그인 직후 '일부 업무는 자동 로그인하지 못했습니다'
화면에 이 둘이 뜹니다.

## 화면을 고칠 때

- **색만** → `index.html`의 테마(네이비 / 모노)를 고칩니다.
- **레이아웃·기능** → `apps/report.html` 또는 `apps/sales.html`을 고쳐 같은 이름으로 덮어 올립니다.
- **메뉴 이름·순서** → 화면의 **메뉴 편집**에서 고치고 **파일에 고정**으로 받은 `index.html`을 올립니다.

## 참고

- 퇴근보고는 로그인 계정과 멘토 이름을 짝지어 둡니다. 로그인 이름이 멘토 명단에 있으면 자동 연결되고,
  없으면 화면에서 본인을 한 번 고르면 됩니다.
- 상담 매출 관리는 원래 구글 로그인도 쓸 수 있습니다. 통합 계정은 이메일·비밀번호로 연결되니,
  구글 계정으로 쌓아 둔 기록이 있으면 계정이 달라 안 보일 수 있습니다.
- Ctrl+P 를 누르면 인트라넷 메뉴 없이 지금 보고 있는 화면만 인쇄됩니다.
